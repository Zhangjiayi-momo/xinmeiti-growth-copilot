# 微信小程序伴侣

这是无需 npm 安装的原生微信小程序版本，可以直接使用微信开发者工具导入 `apps/miniapp`。

## 当前页面

- 总览：累计成本、互动、订单、ROAS 和高表现记录
- 记录：按平台筛选、查看指标、编辑和删除
- 快速录入：成本和流量/互动/转化数据录入

## 导入方式

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择 `D:\Codex\xinmeiti-growth-copilot\apps\miniapp`。
4. 当前使用 `touristappid` 便于本地预览；正式开发请替换为你的小程序 AppID。
5. 点击“编译”即可运行。

## 数据说明

小程序当前独立使用微信本地存储，不会自动与 Web 端同步。下一阶段需要增加后端 API 后再进行跨端同步。

## 正式发布前

- 替换正式 AppID
- 配置隐私政策和用户协议
- 配置 HTTPS 请求域名及 ICP 备案
- 确认服务类目与生成式 AI 合规要求
