# 验收清单

## 功能

- [x] 可新建、编辑和删除营销战役
- [x] 可新建、编辑和删除内容/达人记录
- [x] 成本和原始指标可完整录入
- [x] 派生指标自动计算
- [x] 可按战役、平台和关键词筛选记录
- [x] 可按效率和原始指标排序
- [x] 可填写复盘行动、负责人和备注
- [x] 可导出复盘报告
- [x] 可使用标准 CSV 模板批量导入
- [x] 可导出 CSV 和 JSON
- [x] 可恢复演示数据和清空本地数据
- [x] 可新增 24 小时、72 小时、7 天等指标快照
- [x] 可查看快照时间轴并自动更新当前指标
- [x] 可查看系统建议、置信度并一键采用
- [x] 小程序可查看总览、筛选记录和快速录入

## 数据口径

- [x] 总成本包含报价、广告费、样品成本和服务费
- [x] 互动数包含点赞、收藏、评论和分享
- [x] CPE、CPA、ROAS、ROI 使用统一纯函数
- [x] 分母为零时返回空值，不产生 Infinity 或 NaN
- [x] 聚合 ROI 使用总毛利和总成本，不平均单条 ROI
- [x] 效率指数仅在相同平台和记录类型内比较
- [x] 无收入数据时不显示虚假 ROI

## 安全与稳定性

- [x] 外部链接仅允许 HTTP/HTTPS
- [x] 用户输入在 HTML 中转义
- [x] CSV 导出阻止常见公式注入
- [x] 重启后数据仍保留在浏览器
- [x] 自动化测试覆盖核心公式、模型和 CSV
- [x] 五个页面通过无头浏览器渲染检查
