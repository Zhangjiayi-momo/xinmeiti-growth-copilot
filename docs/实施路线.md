# 实施路线

## 当前已完成：Web v0.4 与小程序伴侣 v0.1

- 原生 ES Modules 单页应用，无第三方运行时依赖
- 战役、内容、达人、成本和效果数据模型
- 营销战役 CRUD
- 内容/达人记录 CRUD
- CPM、CPE、CTR、CVR、CPA、ROAS、ROI
- 同平台、同记录类型、同粉丝层级的效率指数
- 总览看板与行动提示
- 数据复盘和行动状态
- CSV 模板、CSV 导入导出、JSON 备份
- Node 内置服务器
- 指标快照与趋势计算
- 基于同类样本的系统行动建议
- 原生微信小程序总览、记录和快速录入
- IndexedDB + localStorage 双持久化
- SVG 快照增长图
- CPE、转化断层、质量下降和数据过期检测
- Excel 兼容导出
- 版本化本地数据 API
- 同源自动同步、手动推送与版本冲突保护
- 真实 XLSX 导出
- 四档 benchmark 范围
- 战役周度成本与收入趋势
- 纯函数测试、浏览器烟测和构建检查

## 下一阶段：Web v0.5

1. 接入 CloudBase/PostgreSQL，实现多账号团队协作和角色权限。
2. 增加 XLSX 导入、模板版本管理和数据校验报告。

## 第三阶段：云端版本

1. 使用 CloudBase 或 NestJS + PostgreSQL。
2. 增加登录、团队、角色和审计日志。
3. 使用签名临时链接替代公开分享。
4. 所有 AI API 密钥放在服务端。
5. 增加自动备份和导出归档。

## 第四阶段：AI 策略助手

AI 只能在数据基础上给出建议：

- 从 Brief 中提取目标、人群、卖点和约束。
- 引用历史高表现记录生成选题和内容结构。
- 对低效记录给出可验证的优化假设。
- 生成下一轮 A/B 测试方案。
- 输出时显示依据记录、样本量和缺少的数据。

## 后续阶段：微信小程序增强

原生小程序基础版已经完成；后续可继续增强或迁移到 Taro + React + TypeScript。

第一期小程序仅做：

- 快速录入
- 核心看板
- 达人排名
- 复盘提醒
- 只读报告分享

正式发布前需要准备 AppID、主体资质、隐私政策、HTTPS 备案域名和微信平台要求的相关材料。
