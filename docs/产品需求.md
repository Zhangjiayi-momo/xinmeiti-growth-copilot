# 产品需求：新媒体增长作战台

## 1. 产品定位

以营销战役为中心，连接内容策略、达人合作、效果数据和复盘行动。核心价值不是生成更多文案，而是让每一次内容与投放都有清晰目标、统一口径和可执行结论。

## 2. 第一版用户

- 新媒体运营
- 内容运营
- 达人商务与投放执行人员
- 需要复盘内容效果的品牌负责人

## 3. 核心闭环

```text
创建营销战役
→ 配置目标、预算、平台和人群
→ 添加内容或达人合作记录
→ 录入曝光、互动、成本和转化数据
→ 自动计算效率与 ROI
→ 给出继续投放、暂停、优化或重测建议
→ 导出复盘报告
```

## 4. 第一版页面

### 总览看板

- 总花费、曝光、互动、订单、收入
- 互动率、CPE、CPA、ROAS、ROI
- 最佳和待优化记录
- 各记录成本与收入对比

### 投放战役

- 新增、编辑、删除战役
- 目标、预算、平台、人群、周期和负责人
- 查看预算使用情况

### 内容与达人

- 内容记录和达人合作记录统一管理
- 成本、流量、互动、点击、订单和收入字段
- 搜索、平台筛选、排序、编辑和删除

### 数据复盘

- 在同一平台和同记录类型内计算效率指数
- 查看最佳、最差和待行动记录
- 标记继续投放、暂停、优化素材、更换达人或延长观察
- 导出周报文本

### 导入导出

- 下载标准 CSV 模板
- 批量导入 CSV
- 导出 CSV 和 JSON
- 恢复演示数据

## 5. 暂不进入第一版

- 平台爬虫与未授权数据抓取
- 微信登录和团队权限
- 公开 AI 接口
- 微信小程序发布
- 自动广告平台对接

## 6. 验收标准

- 核心指标公式透明，分母为零时不出现 Infinity 或 NaN
- 批量导入至少 50 条记录时不丢失字段
- 同一战役的达人可按效率和原始指标排序
- 数据刷新后仍保留
- 可导出 CSV/JSON 周报数据
- 页面在桌面和移动宽度下均可用
