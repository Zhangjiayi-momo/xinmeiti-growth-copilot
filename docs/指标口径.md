# 指标口径

## 通用原则

1. 先保存原始指标，再计算派生指标。
2. 所有公式由确定性代码执行，不允许 AI 直接计算结果。
3. 没有收入和毛利时，只能展示效率指标，不能宣称 ROI。
4. 跨平台比较必须注明平台、记录类型、粉丝层级和内容类型。

## 成本

```text
总成本 = 达人报价 + 广告投放费 + 样品成本 + 服务费
```

## 内容与互动

```text
互动数 = 点赞 + 收藏 + 评论 + 分享
互动率 = 互动数 ÷（阅读/播放量，缺失时使用曝光量）
```

## 流量效率

```text
CPM = 总成本 ÷ 曝光量 × 1000
CPE = 总成本 ÷ 互动数
CTR = 点击量 ÷ 曝光量
```

## 转化效率

```text
CVR = 订单数 ÷ 点击量
CPA = 总成本 ÷ 订单数
```

## 收入与 ROI

```text
ROAS = 归因收入 ÷ 总成本
ROI =（归因毛利 - 总成本）÷ 总成本
```

归因毛利指收入扣除商品、履约和退款等直接成本后的毛利，不扣除本次投放费用。使用 ROAS 或 ROI 时必须记录归因窗口。

## 效率指数

效率指数用于同一平台、同一记录类型内的相对比较，不是绝对质量分。

```text
互动表现权重 40%，越高越好
CPE 权重 35%，越低越好
ROAS 权重 25%，越高越好
```

没有 ROAS 时，将第三项替换为 CPA 的同类排名；没有对应数据时自动重新分配可用权重。页面必须同时展示原始指标和样本数量。

当同层级有效样本少于 5 条时，只应作为线索，不应作为投放决策的唯一依据。
## 异常检测

异常检测用于发现问题，不直接替代运营判断。当前规则包括：

- CPE 超过同平台、同记录类型中位数的 1.5 倍
- CTR 高于同类中位数 20%，但 CVR 低于同类中位数 30%
- 阅读/播放增长比互动增长高 35 个百分点以上
- 转化目标下存在投放成本但订单为 0
- 最新数据超过 7 天未更新
- 记录没有时间快照

高优先级异常应优先检查数据完整性、归因配置和承接页面，再决定暂停或扩量。
