# 数据字典

## Campaign 营销战役

| 字段 | 类型 | 说明 |
|---|---|---|
| id | string | 战役唯一标识 |
| name | string | 战役名称 |
| brand | string | 品牌名称 |
| product | string | 产品或服务 |
| objective | enum | 内容互动、涨粉、种草、线索获取、成交转化、品牌曝光 |
| audience | string | 目标人群描述 |
| platforms | string[] | 投放平台 |
| budget | number | 总预算 |
| startDate/endDate | date | 起止日期 |
| owner | string | 负责人 |
| notes | string | 补充说明 |

## Record 内容/达人记录

| 字段 | 类型 | 说明 |
|---|---|---|
| id | string | 记录唯一标识 |
| campaignId | string | 所属营销战役 |
| recordType | enum | content 或 creator |
| name | string | 内容名称或合作名称 |
| platform | string | 平台 |
| creatorName | string | 达人昵称，内容自营可为空 |
| followers | number | 达人粉丝数 |
| url | string | 内容链接 |
| publishedAt | date | 发布时间 |
| fees.quote | number | 达人报价 |
| fees.adSpend | number | 广告投放费 |
| fees.sampleCost | number | 样品成本 |
| fees.serviceCost | number | 服务费 |
| metrics.impressions | number | 曝光量 |
| metrics.views | number | 阅读量或播放量 |
| metrics.likes | number | 点赞 |
| metrics.favorites | number | 收藏 |
| metrics.comments | number | 评论 |
| metrics.shares | number | 分享 |
| metrics.follows | number | 涨粉或关注 |
| metrics.clicks | number | 点击 |
| metrics.orders | number | 订单或转化数 |
| metrics.revenue | number | 归因收入 |
| metrics.grossProfit | number | 归因毛利，不含投放费用 |
| review.action | enum | 复盘行动 |
| review.note | string | 复盘结论 |
| review.owner | string | 行动负责人 |
| review.dueAt | date | 行动截止日期 |
| source | string | manual、csv、demo 或 api |
| capturedAt | datetime | 数据采集时间 |

## 关系

```text
Campaign 1 ─── n Record
Record 1 ─── 1 Review
Record 1 ─── n MetricSnapshot
```

每条 Record 可以关联多条 MetricSnapshot。当前数据等于时间最新的快照，历史快照用于观察 24 小时、72 小时、7 天和 30 天的增长或衰退。
